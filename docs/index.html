Dock · Uplink

Bonded, so one bad link doesn't end the stream

Point it at an srtla:// ingest and the stream is split across Wi-Fi, Ethernet and cellular at once. Adaptive bitrate backs off when the network struggles and climbs back as soon as it clears.

  • DestinationsKick, Twitch, YouTube and Restream presets, plus any RTMP, RTMPS, SRT or SRTLA server.
  • CodecsHEVC where the ingest takes it, H.264 where it doesn't, chosen per destination.
  • ReconnectsRetries with backoff and tells you out loud when the stream drops and comes back.
  • BackgroundKeeps streaming while you check a message or open Maps.

Build your own copy, from Windows

MetaStream isn't on the App Store. You build it from the source with your own Apple Developer team: GitHub's macOS runners compile it, and you install it over USB from Windows, Linux or a Mac. No Mac needed at any point.

  1. Fork the repo and pick your bundle ID.
  2. Add your Apple signing and the platform apps you want as GitHub secrets.
  3. Push to main. The build-ipa workflow signs an encrypted IPA.
  4. Download it, decrypt it and install it over USB with pymobiledevice3.
Read the build guideAll features
# every build, from the repo root
gh run download -n MetaStream-ipa -D build
openssl enc -d -aes-256-cbc -pbkdf2 \
  -in build/MetaStream.ipa.enc -out build/MetaStream.ipa \
  -pass file:signing/ipa-password.txt
pymobiledevice3 apps install build/MetaStream.ipa
